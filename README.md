# Путеводитель по итоговому сочинению

Бесплатный сайт для подготовки к итоговому сочинению. Работает на GitHub Pages: сервер и оплата не нужны.

**Что внутри**

| № | Раздел | Что там |
| --- | --- | --- |
| 01 | Критерии и правила | объём, как считают слова, пять критериев, формула зачёта |
| 02 | Разделы и подразделы | все 11 подразделов с примерами тем и ссылками на аргументы |
| 03 | С чего начать | алгоритм, тезис под аргументы, формулы тезиса, частые ошибки |
| 04 | Клише-шаблоны | фразы по частям сочинения и по 8 типам тем, автоподстановка «моих слов» |
| 05 | Идеальные сочинения | 6 работ на зачёт по всем критериям, тезис выделен |
| 06 | Темы и тезисы | 57 тем с тезисами, 10 подробных планов, список литературы |
| 07 | Аргументы | разобранные аргументы с микровыводом + около 450 аргументов из сборников |
| 08 | Произведения | около 195 произведений: герои, пересказ по главам; 67 полных текстов классики |
| 09 | Конструктор | тема → тип темы → тезис → подбор произведений → черновик с проверкой по критериям |
| 10 | В день сочинения | план на 3:55, чек-лист, счётчик слов по правилам экзамена |

Отсчёт до сочинения считается от сегодняшней даты посетителя и после основной даты сам переключается на декабрь следующего года (первая среда декабря,
дополнительные сроки — первая среда февраля и первая рабочая среда мая).

Как опубликовать сайт и включить регистрацию — в [SETUP.md](SETUP.md).

## Источники

«Всё об итоговом сочинении» и идеальные сочинения (Вера Флекс, ЕГЭFLEX), «Темы и тезисы»
(ОК ЕГЭ: К. Кафтаева, О. Беляева), клише (@asyarusichka_el), аргументы VOSH.NETWORK,
сборник «Все аргументы по разделу „Духовно-нравственные ориентиры“», сборник аргументов 2021/22.
Полные тексты — [ilibrary.ru](https://ilibrary.ru), только произведения в общественном достоянии.
Для произведений, которые ещё охраняются авторским правом, даны пересказ и ссылка.
